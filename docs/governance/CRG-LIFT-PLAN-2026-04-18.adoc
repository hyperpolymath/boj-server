== Companion Document

Read `docs/governance/CRG-AUDIT-2026-04-18.adoc` first. This plan acts on its
findings. No implementation is performed in the session that drafts this plan.

== Current -> Target

- *Current:* D (Alpha). Solidly earned. Not aspirational.
- *Immediate target:* C (Alpha-stable, Self-Validated).
- *Medium-term target:* B (Beta, Broadly Validated).

v2.0 forbids publication below B. BoJ's external-facing materials (Show HN
post, arXiv draft, blog post drafts in `docs/outreach/`, `docs/papers/`) are
*blocked* on reaching B before non-abstract publication.

== Tractability Legend

- *S* — session-tractable (hours). One or two focused sessions closes it.
- *M* — multi-session (days–small weeks). Within author control.
- *L* — calendar-slow (weeks–months). Depends on external humans, not
  author effort.

=== 1.4 Exit criteria for Phase 1 (promotion to C)

A promotion commit to C must be justified by *all* of:

1. Every cartridge has a README containing the six fields listed in 1.1.a.
2. `cartridges/`, `.machine_readable/`, `ffi/zig/src/`, `src/abi/Boj/`
   each contain a per-directory README.
3. `docs/READINESS.adoc` is v2.0-aligned and dated 2026-04-XX.
4. `docs/practice/DOGFOOD-LOG.adoc` exists with at least one dated entry per
   home-dogfooded cartridge.
5. CI `zig-test.yml` last run is green; `panic-attack assail` run clean;
   `idris2 --check` passes; no new non-axiomatic `believe_me`.
6. `STATE.a2ml` updated: `grade = "C-alpha-stable"`, completion %, session
   entry for the promotion.

Phase 1 total effort: *session-tractable across ~3-5 focused sessions.*

== Phase 2 — C to B (external targets)

This is the hard part. v2.0 B requires *6+ diverse external targets* with
issues fed back. *No amount of author effort substitutes for this.*

=== 2.1 Recruit external targets (the blocker)

[cols="1,4,1,4"]
|===
| ID | Work item | Effort | Notes

| 2.1.a

running Claude Desktop is not diverse. Target matrix should span: (i) at least

=== 2.2 Publication gate

v2.0 forbids publication below B. Therefore:

- Hold `docs/outreach/show-hn-post.md`, `docs/papers/` arXiv draft, blog drafts
  *until Phase 2 exit*. The content can be kept hot; the button press waits.
- `STATE.a2ml [critical-next-actions]` currently lists Show HN and arXiv as
  next actions; this plan recommends *not* executing them until B is earned.
  Add an explicit "gated on CRG B" note to those entries.

=== 2.3 Exit criteria for Phase 2 (promotion to B)

1. At least 6 diverse external targets have exercised BoJ, diversity per the
   matrix defined in 2.1.a.
2. Per target: one recorded session, one issue (or confirmed nil-issue) fed
   back, one bugfix or "no-change-needed" disposition logged.
3. `docs/READINESS.adoc` updated with per-cartridge B justification where claimed.
4. `STATE.a2ml` updated: `grade = "B-beta"` with supporting session-history
   entries citing the 6 targets.

Phase 2 total effort: *calendar-slow.* Planning is session-tractable; signal is
not.
