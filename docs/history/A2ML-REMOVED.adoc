= The A2ML files removed from boj-server on 2026-11-14

The owner approved on 2026-11-14 moving boj-server off A2ML, as
hyperpolymath/hypatia#1113 did for hypatia. Every `.a2ml` file in boj-server is
translated into deed form where a mapping spec says it translates, every reader
in this repository is moved off it, and the file is deleted. The mapping specs
are in standards `1-formats/deed/mappings/`; a field a spec does not list does
not translate and was dropped, not re-homed. Files with no mapping spec were
deleted when nothing reads them (A7 section 11, ruling Q7).

This record lists each removed file, what it was, and where its content went.
The contents are not copied here. Git history keeps them. To read one, use its
blob id, or read its path at the last commit that held it:

[source,bash]
----
git cat-file -p <blob id>
git show ad5bcdb6370124980e0fd94e4205f1e6def9a52e:<path>
----

Size is in bytes. The sha256 is of the file as it was tracked.

The deed carriers are `boj-server_chora.deed` (the one repo deed) and
`0-AI-MANIFEST.deed` (the pointer-only front door). Both pass
`deed_lint.js`; the chora deed also passes `deed_lint.js --anchor`.
