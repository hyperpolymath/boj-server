= Hardware Security Module (HSM) Integration
:toc: preamble
:icons: font

[TIP]
====
**HSM Status:** This document outlines the Hardware Security Module integration strategy for BOJ Server Mistral. Current implementation uses software-based cryptography with HSM-ready architecture patterns.
====

== Why HSM Matters for BOJ Server

**Threat Model:**
* Software-based cryptography vulnerable to memory extraction attacks
* Private keys exposed in process memory during operations
* Side-channel attacks on cryptographic operations
* Insider threats from compromised nodes
* Physical security requirements for compliance (FIPS 140-2 Level 3/4)

**Critical Assets Requiring HSM Protection:**
* **RoKur Secrets:** Master encryption keys for user data
* **Vordr Ephemeral Keys:** Short-lived session keys for gossip protocol
* **Svalinn Attestation Keys:** Root of trust for node identity
* **Cerro-Torre Signing Keys:** Document signing authority
* **Database Encryption Keys:** Protection for sensitive submissions

pub trait HsmProvider: Send + Sync {
    /// Sign data with a specific key
    fn sign(&self, key_id: &str, data: &[u8]) -> Result<Vec<u8>>;
    
    /// Verify signature
    fn verify(&self, key_id: &str, data: &[u8], signature: &[u8]) -> Result<bool>;

    fn health_check(&self) -> Result<HsmHealth>;

// src/security/hsm/pkcs11.rs
use pkcs11::*;

pub struct Pkcs11Provider {
    context: Context,
    session: Session,
    slot: Slot,
}

impl HsmProvider for Pkcs11Provider {
    fn sign(&self, key_id: &str, data: &[u8]) -> Result<Vec<u8>> {
        let object = self.find_key_object(key_id)?;
        
        let mut signature = vec![0u8; 256]; // Max signature size
        let mut signature_len = signature.len();
        
        self.session.sign_init(
            &Mechanism::Ecdsa,
            &object,
        )?;
        
        self.session.sign(data, &mut signature, &mut signature_len)?;
        signature.truncate(signature_len);
        
        Ok(signature)
    }
    
    fn health_check(&self) -> Result<HsmHealth> {
        // Check session state
        let session_info = self.session.get_session_info()?;
        
        // Check slot status
        let slot_info = self.slot.get_slot_info()?;
        
        Ok(HsmHealth {
            status: HsmStatus::Healthy,
            session_state: session_info.state,
            slot_description: slot_info.description,
        })
    }
}

=== YubiHSM Connector

[source,rust]

// src/security/hsm/yubihsm.rs
use yubihsm::*;

pub struct YubiHsmProvider {
    connector: Connector,
    session: Session,
}

impl YubiHsmProvider {
    pub fn new(connectors: &[usize]) -> Result<Self> {
        let connector = Connector::new(connectors)?;
        let session = connector.create_session_unauthenticated()?;
        Ok(Self { connector, session })
    }
    
    pub fn authenticate(&mut self, password: &str) -> Result<()> {
        let auth = Authentication::new(1, password.as_bytes().to_vec());
        self.session = self.connector.create_session(&auth)?;
        Ok(())
    }
}

impl HsmProvider for YubiHsmProvider {
    fn sign(&self, key_id: &str, data: &[u8]) -> Result<Vec<u8>> {
        let key_id = key_id.parse::<u16>()?;
        let signature = self.session.sign_ecdsa(&SignEcdsaRequest {
            key_id,
            data: data.to_vec(),
        })?;
        Ok(signature.signature)
    }
    
    fn generate_key_pair(&self, algorithm: KeyAlgorithm, key_id: &str) -> Result<()> {
        let key_id = key_id.parse::<u16>()?;
        
        let capabilities = match algorithm {
            KeyAlgorithm::EcdsaP256 => Capabilities::SignEcdsa,
            KeyAlgorithm::Rsa2048 => Capabilities::SignPkcs1,
            KeyAlgorithm::Ed25519 => Capabilities::SignEd25519,
            _ => return Err(HsmError::UnsupportedAlgorithm),
        };
        
        self.session.put_asymmetric_key(&PutAsymmetricKeyRequest {
            id: key_id,
            label: key_id.to_string(),
            domains: 1,
            capabilities,
            algorithm,
        })?;
        
        Ok(())
    }
}

// src/security/hsm/cloudhsm.rs
use aws_sdk_cloudhsm::*;

pub struct CloudHsmProvider {
    client: Client,
    cluster_id: String,
}

impl HsmProvider for CloudHsmProvider {
    fn sign(&self, key_id: &str, data: &[u8]) -> Result<Vec<u8>> {
        let response = self.client.sign(
            &SignRequest {
                key_handle: key_id.to_string(),
                message: data.to_vec(),
                message_type: Some(MessageType::Raw),
                ..Default::default()
            }
        ).await?;
        
        Ok(response.signature)
    }
    
    fn health_check(&self) -> Result<HsmHealth> {
        let response = self.client.describe_clusters(
            &DescribeClustersRequest {
                filters: Some(vec![Filter {
                    name: Some("clusterIds".to_string()),
                    values: Some(vec![self.cluster_id.clone()]),
                }]),
                ..Default::default()
            }
        ).await?;
        
        if let Some(cluster) = response.clusters.first() {
            Ok(HsmHealth {
                status: if cluster.state == ClusterState::Active {
                    HsmStatus::Healthy
                } else {
                    HsmStatus::Degraded
                },
                session_state: SessionState::Active,
                slot_description: cluster.cluster_id.clone(),
            })
        } else {
            Err(HsmError::ClusterNotFound)
        }
    }
}

// src/security/rokur/hsm.rs
pub struct HsmRokurManager {
    hsm: Arc<dyn HsmProvider>,
    key_id: String, // HSM key identifier
}

impl HsmRokurManager {
    pub fn new(hsm: Arc<dyn HsmProvider>, key_id: &str) -> Self {
        Self {
            hsm,
            key_id: key_id.to_string(),
        }
    }
    
    pub fn encrypt_data(&self, data: &[u8]) -> Result<Vec<u8>> {
        // Generate ephemeral key
        let ephemeral_key = generate_ephemeral_key()?;
        
        // Encrypt data with ephemeral key
        let ciphertext = encrypt_with_ephemeral(data, &ephemeral_key)?;
        
        // Wrap ephemeral key with HSM-protected master key
        let wrapped_key = self.hsm.encrypt(&self.key_id, &ephemeral_key)?;
        
        // Combine ciphertext and wrapped key
        Ok(combined_output(ciphertext, wrapped_key))
    }
    
    pub fn decrypt_data(&self, encrypted_data: &[u8]) -> Result<Vec<u8>> {
        // Extract wrapped key and ciphertext
        let (ciphertext, wrapped_key) = split_input(encrypted_data)?;
        
        // Unwrap ephemeral key using HSM
        let ephemeral_key = self.hsm.decrypt(&self.key_id, &wrapped_key)?;
        
        // Decrypt data with ephemeral key
        decrypt_with_ephemeral(&ciphertext, &ephemeral_key)
    }
}

// src/network/vordr/hsm.rs
pub struct HsmVordrKeyManager {
    hsm: Arc<dyn HsmProvider>,
    key_cache: LruCache<String, Vec<u8>>, // Cache public keys
}

impl HsmVordrKeyManager {
    pub fn generate_ephemeral_key(&self, session_id: &str) -> Result<EphemeralKeyPair> {
        // Generate key pair in HSM
        let key_id = format!("vordr_ephemeral_{}", session_id);
        self.hsm.generate_key_pair(KeyAlgorithm::X25519, &key_id)?;
        
        // Export public key (safe to cache)
        let public_key = self.hsm.export_public_key(&key_id)?;
        
        // Cache public key for performance
        self.key_cache.put(key_id.clone(), public_key.clone());
        
        Ok(EphemeralKeyPair {
            key_id,
            public_key,
        })
    }
    
    pub fn perform_key_exchange(&self, key_pair: &EphemeralKeyPair, peer_public_key: &[u8]) -> Result<Vec<u8>> {
        // This would be implemented using HSM's key agreement operations
        // For X25519: hsm.derive_key(&key_pair.key_id, peer_public_key)
        
        // Simplified example - actual implementation uses HSM operations
        let shared_secret = x25519(peer_public_key, &key_pair.public_key)?;
        Ok(shared_secret)
    }
    
    pub fn cleanup_session(&self, key_id: &str) -> Result<()> {
        // In real HSM, we might delete the ephemeral key
        // For YubiHSM: self.hsm.delete_object(key_id)
        self.key_cache.pop(key_id);
        Ok(())
    }
}

pub struct HsmSvalinnAttestor {
    hsm: Arc<dyn HsmProvider>,

impl HsmSvalinnAttestor {

        Self {
            hsm,
            attestation_key_id: key_id.to_string(),
        }
    }
    
    pub fn create_attestation(&self, measurement: &Measurement) -> Result<Attestation> {
        // Serialize measurement data
        let data = measurement.serialize()?;
        
        // Sign with HSM-protected key
        let signature = self.hsm.sign(&self.attestation_key_id, &data)?;
        
        // Get current HSM certificate chain
        let cert_chain = self.get_hsm_certificate_chain()?;
        
        Ok(Attestation {
            measurement: measurement.clone(),
            signature,
            certificate_chain: cert_chain,
            timestamp: Utc::now(),
        })
    }
    
    fn get_hsm_certificate_chain(&self) -> Result<Vec<Certificate>> {
        // Implementation depends on HSM type
        // For YubiHSM: export device certificate
        // For CloudHSM: get AWS certificate chain
        Ok(vec![])
    }
    
    pub fn verify_attestation(&self, attestation: &Attestation) -> Result<bool> {
        // Verify signature using HSM
        let data = attestation.measurement.serialize()?;
        self.hsm.verify(
            &self.attestation_key_id,
            &data,
            &attestation.signature
        )
    }

=== Fallback Strategies

**Graceful Degradation Pattern:**
[source,rust]
--
// src/security/hsm/fallback.rs
pub struct FallbackHsmProvider {
    primary: Arc<dyn HsmProvider>,
    secondary: Option<Arc<dyn HsmProvider>>,
    software_fallback: SoftwareHsm,
    failure_counter: AtomicUsize,
}

impl HsmProvider for FallbackHsmProvider {
    fn sign(&self, key_id: &str, data: &[u8]) -> Result<Vec<u8>> {
        // Try primary HSM
        match self.primary.sign(key_id, data) {
            Ok(sig) => {
                self.failure_counter.store(0, Ordering::Relaxed);
                return Ok(sig);
            }
            Err(e) if self.is_recoverable_error(&e) => {
                // Try secondary HSM if available
                if let Some(secondary) = &self.secondary {
                    match secondary.sign(key_id, data) {
                        Ok(sig) => {
                            self.failure_counter.fetch_add(1, Ordering::Relaxed);
                            return Ok(sig);
                        }
                        Err(_) => {}
                    }
                }
                
                // Fallback to software (with alerts)
                let sig = self.software_fallback.sign(key_id, data)?;
                self.report_fallback_usage();
                Ok(sig)
            }
            Err(e) => Err(e),
        }
    }
    
    fn is_recoverable_error(&self, error: &HsmError) -> bool {
        matches!(error, HsmError::ConnectionFailed | HsmError::Timeout | HsmError::Overloaded)
    }
    
    fn report_fallback_usage(&self) {
        // Alert monitoring system
        metrics::increment_counter!("hsm.software_fallback.used");
        
        // Log critical event
        error!("HSM fallback activated - potential security degradation");
        
        // Trigger incident response if repeated failures
        if self.failure_counter.fetch_add(1, Ordering::Relaxed) > 5 {
            alert::trigger_security_incident("HSM repeated failures");
        }
    }
}

=== Emergency Recovery Procedures

**HSM Recovery Playbook:**

1. **Detection:**
   - Monitoring alerts on HSM failures
   - Automated health check failures
   - Manual incident reporting

2. **Containment:**
   - Activate fallback mode
   - Rate limit cryptographic operations
   - Alert security team

3. **Diagnosis:**
   - Check HSM hardware status
   - Verify network connectivity
   - Test with alternative clients

4. **Recovery:**
   - Restart HSM service
   - Failover to backup HSM
   - Initiate key recovery procedure

5. **Post-Incident:**
   - Rotate affected keys
   - Analyze failure cause
   - Update runbooks

=== HSM Security Policies

**Key Management Policies:**

1. **Key Generation:** All master keys generated within HSM
2. **Key Export:** Private keys never exportable (extractable=false)
3. **Key Usage:** Restrict keys to specific operations (sign-only, decrypt-only)
4. **Key Rotation:** Automated rotation with overlap period
5. **Key Destruction:** Secure zeroization of deleted keys

**Access Control Policies:**

1. **Role-Based Access:** Separate crypto officer and crypto user roles
2. **Dual Control:** Require multiple administrators for sensitive operations
3. **Audit Logging:** Comprehensive logs of all HSM operations
4. **Session Timeout:** Short-lived sessions with automatic logout
5. **Physical Security:** HSM in secure data center with access controls

=== Key Migration Procedure

**Step-by-Step Key Migration:**

1. **Backup Existing Keys:**
   - Export all software keys to secure storage
   - Verify backups are intact and recoverable

2. **Generate New HSM Keys:**
   - Create new key pairs in HSM
   - Never import software keys to HSM

3. **Dual-Signing Period:**
   - Both old and new keys active
   - Clients accept signatures from either key

4. **Gradual Rollout:**
   - Update services one by one
   - Monitor for issues at each step

5. **Old Key Decommissioning:**
   - Phase out software keys
   - Revoke old keys after migration complete

6. **Verification:**
   - Audit all cryptographic operations
   - Confirm HSM usage in logs

== Documentation & Training

=== Developer Guide

**Integrating HSM in New Services:**

1. **Add HSM Dependency:**
   ```toml
   [dependencies]
   boj-hsm = { path = "../hsm" }
   ```

2. **Initialize HSM Provider:**
   ```rust
   let hsm = HsmProvider::new_from_config().await?;
   ```

3. **Use HSM for Cryptographic Operations:**
   ```rust
   // Signing
   let signature = hsm.sign("my_service_key", &data)?;
   
   // Encryption
   let ciphertext = hsm.encrypt("data_encryption_key", &plaintext)?;
   ```

4. **Handle Failures Gracefully:**
   ```rust
   match hsm.sign("key_id", &data) {
       Ok(sig) => { /* use signature */ }
       Err(HsmError::ConnectionFailed) => {
           // Activate fallback or retry
           fallback_sign(&data)
       }
       Err(e) => return Err(e.into()),
   }
   ```

=== Operations Guide

**HSM Administration:**

1. **YubiHSM Setup:**
   ```bash
   # Install YubiHSM tools
   brew install yubihsm-shell
   
   # Initialize HSM
   yubihsm-shell -c "connect"
   yubihsm-shell -c "session open 1 password"
   yubihsm-shell -c "generate asymmetric key 0x1234 rokur_master_key ecdsa-p256"
   ```

2. **Key Rotation:**
   ```bash
   # Using BOJ admin tools
   boj-admin hsm rotate-key --key-id rokur_master --new-key-id rokur_master_v2
   boj-admin hsm verify-rotation --old-key rokur_master --new-key rokur_master_v2
   ```

3. **Monitoring:**
   ```bash
   # Check HSM health
   boj-admin hsm health-check
   
   # View operation metrics
   boj-admin hsm metrics
   ```
