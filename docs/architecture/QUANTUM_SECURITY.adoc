== Why Quantum Security Matters

**Threat Model:**
* Shor's algorithm can break RSA/ECC in polynomial time on quantum computers
* Grover's algorithm reduces symmetric key security by 50%
* Harvest-now-decrypt-later attacks on current communications
* BOJ Server handles sensitive code submissions and user data requiring long-term protection

**Current Vulnerabilities:**
* JWT signing uses RSA/HS256 (quantum-vulnerable)
* TLS 1.3 with X25519/ECDSA (quantum-vulnerable)
* Svalinn attestations use classical signatures
* Cerro-Torre signatures use ECDSA

=== JWT Hybrid Signing Implementation

[source,rust]
--
// src/auth/jwt.rs
use oqs::sig;

pub struct HybridJwtSigner {
    classical_key: rsa::RsaPrivateKey,
    pq_key: sig::Sig,
}

impl HybridJwtSigner {
    pub fn new() -> Self {
        // Initialize classical RSA key
        let classical_key = rsa::RsaPrivateKey::new(&mut rand::thread_rng(), 4096).unwrap();
        
        // Initialize post-quantum Dilithium3 key
        let pq_key = sig::Sig::new(sig::Algorithm::Dilithium3).unwrap();
        
        Self { classical_key, pq_key }
    }
    
    pub fn sign(&self, claims: &Claims) -> Result<HybridToken> {
        // Step 1: Sign with classical algorithm
        let classical_token = encode(
            &Header::default(), 
            claims, 
            &EncodingKey::from_rsa_pem(&classical_key.to_pem())
        )?;
        
        // Step 2: Sign the classical token with PQ algorithm
        let pq_signature = self.pq_key.sign(classical_token.as_bytes())?;
        
        // Step 3: Combine into hybrid token
        Ok(HybridToken {
            classical: classical_token,
            post_quantum_signature: pq_signature,
            algorithm: "RS256+Dilithium3".to_string(),
        })
    }
}

use rustls::crypto::ring::default_provider;
use oqs::kem;

pub fn configure_post_quantum_tls() -> ServerConfig {
    let mut config = ServerConfig::builder()
        .with_safe_defaults()
        .with_no_client_auth();
    
    // Add post-quantum key exchange
    let kem = kem::Kem::new(kem::Algorithm::Kyber768).unwrap();
    config.key_exchange_algorithms.push("kyber768".to_string());
    
    // Configure hybrid cipher suites
    config.cipher_suites = vec![
        rustls::CipherSuite::TLS13_CHACHA20_POLY1305_SHA256,
        rustls::CipherSuite::TLS13_AES_256_GCM_SHA384,
    ];
    
    config
}

[source,rust]

// src/security/svalinn.rs
use oqs::sig;

pub struct HybridAttestor {
    ecdsa_key: EcdsaPrivateKey,
    sphincs_key: sig::Sig,  // SPHINCS+ for conservative security
}

impl HybridAttestor {
    pub fn new() -> Self {
        Self {
            ecdsa_key: EcdsaPrivateKey::generate_pkcs8(&mut rand::thread_rng()).unwrap(),
            sphincs_key: sig::Sig::new(sig::Algorithm::SPHINCSPlusSha256128fSimple).unwrap(),
        }
    }
    
    pub fn attest(&self, measurement: &Measurement) -> Result<HybridAttestation> {
        let data = measurement.serialize()?;
        
        // Classical ECDSA signature
        let ecdsa_sig = self.ecdsa_key.sign(&data);
        
        // Post-quantum SPHINCS+ signature
        let sphincs_sig = self.sphincs_key.sign(&data)?;
        
        Ok(HybridAttestation {
            measurement: measurement.clone(),
            ecdsa_signature: ecdsa_sig,
            sphincs_signature: sphincs_sig,
            timestamp: Utc::now(),
        })
    }
}

=== Hybrid Key Storage
[source,rust]
--
// src/security/key_manager.rs
pub struct HybridKeyPair {
    classical: ClassicalKeyMaterial,
    post_quantum: PostQuantumKeyMaterial,
    metadata: KeyMetadata,
}

impl HybridKeyPair {
    pub fn rotate(&mut self) -> Result<()> {
        // Generate new classical key
        let new_classical = RsaPrivateKey::new(&mut rand::thread_rng(), 4096)?;
        
        // Generate new post-quantum key
        let new_pq = sig::Sig::new(sig::Algorithm::Dilithium3)?;
        
        // Atomic swap
        let old_pair = std::mem::replace(
            self,
            Self {
                classical: new_classical,
                post_quantum: new_pq,
                metadata: KeyMetadata::new_rotation(&self.metadata),
            }
        );
        
        // Archive old keys securely
        self.archive_old_keys(old_pair)?;
        
        Ok(())
    }
}

pub fn verify_token(token: &str) -> Result<Claims> {
    // Try hybrid format first
    if let Ok(hybrid) = HybridToken::parse(token) {
        return hybrid.verify_hybrid();
    }
    
    // Fallback to classical format
    if let Ok(classical) = ClassicalToken::parse(token) {
        return classical.verify_classical();
    }

    }

=== Developer Guide

**Migrating Existing Code:**

1. **Identify cryptographic operations:**
   - Search for `rsa`, `ecdsa`, `sign`, `verify` in codebase
   - Identify all JWT, TLS, and custom crypto usage

2. **Implement hybrid wrappers:**
   - Wrap existing crypto calls with hybrid equivalents
   - Maintain backward compatibility

3. **Update dependencies:**
   - Add `oqs = "0.8.0"` to Cargo.toml
   - Update TLS libraries to PQ-ready versions

4. **Test thoroughly:**
   - Verify hybrid signatures work
   - Test fallback to classical
   - Performance benchmarking

=== User Migration Guide

**For API Consumers:**

1. **No immediate action required** - hybrid tokens work with existing clients
2. **Update SDKs by Q3 2025** for full PQ support
3. **Monitor deprecation notices** for classical-only endpoints

**For Node Operators:**

1. **Upgrade to BOJ Server v2.0+** for hybrid support
2. **Configure hybrid mode** in server settings
3. **Monitor PQ performance** and adjust resources as needed
