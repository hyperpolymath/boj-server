= BoJ OS - Lightweight Operating System for AI Agents
:toc: preamble
:icons: font

[TIP]
====
**BoJ OS Status:** This document outlines the lightweight operating system design for BoJ Server nodes. Current implementation uses standard Linux distributions with BoJ OS in development.
====

== Why BoJ OS Matters

**Problem Statement:**
* Standard OS distributions include unnecessary components for BoJ nodes
* Lack of optimization for AI workloads and cartridge execution
* Inconsistent environments across deployments
* No built-in support for OTP and Elixir Multiplier
* Security surface area larger than needed

**BoJ OS Goals:**
* **Minimal Footprint:** <100MB base image
* **AI-Optimized:** Pre-configured for cartridge execution
* **Consistent Environment:** Identical across all BoJ nodes
* **Security-Hardened:** Minimal attack surface
* **OTP Support:** First-class Elixir/Erlang support
* **Immutable:** Read-only base with atomic updates

**Custom APKBUILD Example:**
[source,bash]
--
# Maintainer: BOJ OS Team <os-team@boj.example.com>
pkgname=boj-os-base
pkgver=1.0.0
pkgrel=0
pkgdesc="BoJ OS - Minimal OS for AI agents"
url="https://boj.example.com/os"
arch="x86_64 aarch64"
license="PMPL-1.0-or-later"
depends="
    busybox
    s6
    s6-rc
    bearssl
    libressl
    zlib
    musl
"

source="https://github.com/boj-server/boj-os/archive/v$pkgver.tar.gz"

build() {
    cd "$builddir"
    
    # Apply BoJ-specific patches
    patch -p1 < "$srcdir"/patches/0001-boj-optimizations.patch
    
    # Build minimal system
    ./build.sh --minimal --nojournal --noipv6
    
    # Install to package directory
    make DESTDIR="$pkgdir" install
}

package() {
    # Install base system
    cp -r "$builddir"/rootfs/* "$pkgdir"
    
    # Add BoJ-specific configurations
    install -Dm644 "$srcdir"/config/boj-os.conf "$pkgdir"/etc/boj-os.conf
    
    # Set up init system
    install -Dm755 "$srcdir"/init/rc.init "$pkgdir"/etc/s6/rc.init"
}

sha512sums="
    $sha512_boj_os_base
    $sha512_patch_0001
"
--

=== Init System (s6)

**s6 Configuration:**
[source,bash]
--
# /etc/s6/rc.init
#!/bin/execlineb -P

# Mount necessary filesystems
mount -t proc proc /proc
mount -t sysfs sysfs /sys
mount -t devtmpfs devtmpfs /dev
mount -t tmpfs tmpfs /run

# Set up logging
s6-log /run/service/boj-logs

# Start essential services
s6-svscanctl -t 0 /run/service

# BoJ-specific services
s6-supervise /run/service/boj-cartridge-manager
s6-supervise /run/service/boj-network-manager
s6-supervise /run/service/boj-monitoring-agent
s6-supervise /run/service/boj-otp

# Keep system running
pause
--

=== Immutable Updates

**Update Mechanism:**
[source,bash]
--
# BoJ OS Update System

# Current version tracking
BOJ_OS_VERSION="1.0.0"
BOJ_OS_CHANNEL="stable"
BOJ_OS_REPO="https://updates.boj.example.com"

# Update process
boj-os-update() {
    local current_version=$(cat /etc/boj-os-version)
    local latest_version=$(curl -s ${BOJ_OS_REPO}/${BOJ_OS_CHANNEL}/latest)
    
    if [ "$current_version" = "$latest_version" ]; then
        echo "System is up to date (v${current_version})"
        return 0
    fi
    
    echo "Updating BoJ OS from v${current_version} to v${latest_version}"
    
    # Download update package
    local update_package="boj-os-${latest_version}.tar.gz"
    curl -s -o /tmp/${update_package} ${BOJ_OS_REPO}/${BOJ_OS_CHANNEL}/${update_package}
    
    # Verify signature
    gpg --verify /tmp/${update_package}.sig /tmp/${update_package}
    if [ $? -ne 0 ]; then
        echo "Update verification failed!"
        rm -f /tmp/${update_package}*
        return 1
    fi
    
    # Prepare update
    mkdir -p /tmp/boj-os-update
    tar -xzf /tmp/${update_package} -C /tmp/boj-os-update
    
    # Atomic switch
    echo "Performing atomic update..."
    mv /tmp/boj-os-update/rootfs/* /rootfs-new/
    sync
    
    # Switch root filesystem
    pivot_root /rootfs-new /rootfs-old
    
    # Cleanup
    umount /rootfs-old/proc
    umount /rootfs-old/sys
    umount /rootfs-old/dev
    rm -rf /rootfs-old
    
    # Update version
    echo "${latest_version}" > /etc/boj-os-version
    
    echo "Update complete! Please reboot."
    return 0
}

# Rollback function
boj-os-rollback() {
    if [ -d /rootfs-old ]; then
        echo "Rolling back to previous version..."
        pivot_root /rootfs-old /rootfs-new
        sync
        rm -rf /rootfs-new
        echo "Rollback complete! Please reboot."
        return 0
    else
        echo "No previous version available for rollback"
        return 1
    fi
}

# Check for updates
boj-os-check-updates() {
    local current=$(cat /etc/boj-os-version)
    local latest=$(curl -s ${BOJ_OS_REPO}/${BOJ_OS_CHANNEL}/latest)
    
    if [ "$current" != "$latest" ]; then
        echo "Update available: v$latest (current: v$current)"
        return 1
    else
        echo "System is up to date"
        return 0
    fi
}

**Creating Custom Packages:**
[source,bash]
--
# Create package directory
mkdir -p packages/my-package

# Add package files
cat > packages/my-package/APKBUILD <<EOF
pkgname=boj-my-package
pkgver=1.0.0
pkgrel=0
pkgdesc="My custom BoJ package"
url="https://boj.example.com"
arch="all"
license="PMPL-1.0-or-later"
depends="boj-base"

source="$pkgname-$pkgver.tar.gz"

build() {
    cd "$builddir"
    make
}

package() {
    install -Dm755 my-binary "$pkgdir"/usr/bin/my-binary
    install -Dm644 my-config.conf "$pkgdir"/etc/boj/my-config.conf
}
EOF

# Build package
cd packages/my-package
abuild -r
--
