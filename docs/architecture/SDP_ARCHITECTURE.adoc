== 🛡️ SDP Components

### 1. SDP Controller

**Responsibilities:**
- Policy management
- Access brokerage
- Connection orchestration
- Audit logging

**Implementation:**

[source,rust]
----
struct SdpController {
    policy_engine: PolicyEngine,
    access_broker: AccessBroker,
    audit_log: AuditLog,
}

impl SdpController {
    async fn handle_access_request(
        &self,
        request: AccessRequest
    ) -> Result<AccessToken, AccessError> {
        // 1. Validate request
        self.policy_engine.validate(&request)?;
        
        // 2. Generate access token
        let token = self.access_broker.generate_token(&request)?;
        
        // 3. Log access
        self.audit_log.record_access(&request, &token);
        
        Ok(token)
    }
}
---- 

### 2. SDP Gateway

**Responsibilities:**
- QUIC termination
- TLS encryption
- Request forwarding
- Rate limiting

**Implementation:**

[source,rust]
----
struct SdpGateway {
    quic_listener: QuicListener,
    tls_config: TlsConfig,
    rate_limiter: RateLimiter,
    forward_rules: ForwardRules,
}

impl SdpGateway {
    async fn handle_connection(&self, conn: QuicConnection) {
        // 1. Terminate QUIC
        let stream = conn.accept_stream().await?;
        
        // 2. Verify access token
        let token = self.verify_token(stream).await?;
        
        // 3. Apply rate limiting
        self.rate_limiter.check(&token)?;
        
        // 4. Forward request
        self.forward_request(stream, token).await?;
    }
}
---- 

### 3. Policy Engine

**Responsibilities:**
- Access policy evaluation
- Rule-based decisions
- Dynamic updates

**Implementation:**

[source,rust]
----
struct PolicyEngine {
    rules: Vec<AccessRule>,
    evaluator: RuleEvaluator,
}

impl PolicyEngine {
    fn validate(&self, request: &AccessRequest) -> Result<(), PolicyError> {
        for rule in &self.rules {
            if !self.evaluator.evaluate(rule, request)? {
                return Err(PolicyError::Denied);
            }
        }
        Ok(())
    }
}

struct AccessRule {
    condition: Condition,
    action: Action,  // Allow/Deny
    priority: u32,
}
---- 

## 🌐 SDP Enforcement Rules

### 1. Single Route Enforcement

**Rule**: All access must go through SDP Gateway on QUIC port 443

**Implementation:**

[source,bash]
----
# Firewall rules (example for Linux)
iptables -A INPUT -p udp --dport 443 -j ACCEPT

iptables -A INPUT -j DROP  # Drop all other traffic

# SELinux policy
setsebool -P httpd_can_network_connect 1
semanage port -a -t http_port_t -p udp 443

## 🔗 Integration with Stapeln

### 1. Container-Level SDP

[source,rust]
----
struct StapelnSdp {
    container_rules: HashMap<String, SdpPolicy>,
}

impl StapelnSdp {
    async fn apply_container_policy(
        &self,
        container_id: &str
    ) -> Result<(), SdpError> {
        if let Some(policy) = self.container_rules.get(container_id) {
            self.enforce_policy(policy).await?;
        }
        Ok(())
    }
}
----

## 📋 SDP Configuration Example

### 1. SDP Controller Configuration

[source,yaml]
----
sdp:
  controller:
    listen: "0.0.0.0:8443"
    tls:
      cert: "/etc/sdp/cert.pem"
      key: "/etc/sdp/key.pem"
    policies:
      - name: "admin-access"
        condition: "role == 'admin'"
        action: "allow"
        priority: 10
      - name: "default-deny"
        condition: "true"
        action: "deny"
        priority: 100
---- 

### 2. SDP Gateway Configuration

[source,yaml]
----
gateway:
  quic:
    listen: "0.0.0.0:443"
    cert: "/etc/sdp/gateway-cert.pem"
    key: "/etc/sdp/gateway-key.pem"
  rate_limiting:
    requests_per_second: 1000
    burst_capacity: 100
  forwarding:
    default:
      target: "http://boj-server:8000"
    routes:
      - path: "/cartridges/*"
        target: "http://cartridge-service:8080"
---- 

### 3. Firewall Rules (NFTables)

[source,bash]
----
#!/usr/bin/env bash

# Create SDP chain
nft add table inet sdp
nft add chain inet sdp input { type filter hook input priority 0 \; }

# Allow QUIC traffic
nft add rule inet sdp input udp dport 443 accept
nft add rule inet sdp input tcp dport 443 accept

# Allow ICMP
nft add rule inet sdp input icmp type echo-request accept

# Drop all other traffic
nft add rule inet sdp input counter drop

# Enable ruleset
nft list ruleset
---- 

### 4. SELinux Policy

[source,te]
----
policy_module(sdp_gateway, 1.0)

require {
    type httpd_t;
    type http_port_t;
    class tcp_socket name_bind;
    class udp_socket name_bind;
}

# Allow SDP gateway to bind to port 443
allow httpd_t http_port_t:tcp_socket name_bind;
allow httpd_t http_port_t:udp_socket name_bind;

# Allow QUIC protocol
allow httpd_t self:udp_socket create;
----
