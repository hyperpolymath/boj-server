== Overview

Formally verified properties of the BoJ server ABI layer.
All proofs are written in Idris2 and live in `src/abi/Boj/`.

====

toolchain — `cd src/abi && idris2 --typecheck boj.ipkg` builds all 17 modules
clean on Idris2 0.8.0 (Chez backend), the only `believe_me` being the 5
sanctioned class-(J) axioms in `SafetyLemmas.idr`. `CartridgeDispatch` and
`APIContractCoverage` are now listed in `boj.ipkg` (previously omitted, so the
package build never checked them). See `PROOF-NEEDS.md` -> _Build Verification_
for the per-module reconciliation.

== Axiomatic Surface

Five `believe_me` axioms remain, all declared and justified in `SafetyLemmas.idr`:

* `charEqSound` — soundness of `prim__eqChar`
* `charEqSym` — symmetry of `prim__eqChar`
* `unpackLength` — `prim__strToCharList` preserves length
* `appendLengthSum` — `prim__strAppend` length semantics
* `substrLengthBound` — `prim__strSubstr` length bound

All are backend-primitive guarantees that are not reducible at the Idris2 type level.
