== What is BoJ Server?

Bundle of Joy (BoJ) Server is a cartridge-based MCP protocol gateway. Each cartridge (database-mcp, fleet-mcp, nesy-mcp, etc.) is a formally verified Idris2 ABI + Zig FFI + unified adapter triple. The server exposes REST (port 7700), gRPC (7701), GraphQL (7702), and SSE (7703) endpoints. 99 cartridges cover databases, clouds, messaging, CI/CD, git forges, secrets, queues, proofs, and more.

Three-class architecture: Class 1 (simple CLI), Class 2 (orchestrator with webhooks/MQTT), Class 3 (BEAM multiplier for global scale).

== Prerequisites

[cols="1,2,2"]
|===
| Tool | Minimum Version | Install

| Idris2
| >= 0.7.0
| `asdf install idris2 latest`

| Zig
| >= 0.15
| `asdf install zig latest`

| just
| >= 1.25
| `cargo install just`

| Rust / Cargo (optional)
| >= 1.80
| For `tools/cartridge-minter` only

Verify all tools:

[source,bash]
----
just doctor
----

== Clone and First Build

[source,bash]
----
cd ~/Documents/hyperpolymath-repos
git clone https://github.com/hyperpolymath/boj-server.git
cd boj-server
----

Check dependencies:

[source,bash]
----
just deps
----

Build all Zig FFI layers (catalogue + cartridges):

[source,bash]
----
just build
----

== First Run

Build the V-lang adapter and start the server:

[source,bash]
----
just run
----

This builds the Zig FFI, then compiles the V-lang adapter, then starts:

- REST API on http://localhost:7700
- gRPC on port 7701
- GraphQL on port 7702

Check health:

[source,bash]
----
curl http://localhost:7700/status
----

== Smoke Test

Type-check the core ABI and run one FFI test:

[source,bash]
----
just test-smoke
----

Full test suite (catalogue + 17 cartridge FFIs):

[source,bash]
----
just test
----

== Verification

BoJ requires zero `believe_me` in all Idris2 sources. Run the full verification suite:

[source,bash]
----
just verify
----

This runs: typecheck -> verify-no-believe-me -> build -> test.

== Show Capability Matrix

[source,bash]
----
just matrix
----

Shows ABI/FFI/Adapter/Tests status for each cartridge.

== Optional: Cloudflare Tunnel

Expose your local BoJ server publicly:

[source,bash]
----
just serve
----

Starts the server + Cloudflare Quick Tunnel (requires `cloudflared`).

== Project Structure (Key Paths)

----
src/abi/               Idris2 ABI (Catalogue.idr, Protocol.idr, etc.)
ffi/zig/               Zig FFI (catalogue.zig, loader.zig)
adapter/v/             V-lang triple adapter (REST+gRPC+GraphQL)
cartridges/            One dir per cartridge (70+ total)
  database-mcp/        Example: Idris2 ABI + Zig FFI + V adapter
container/             Stapeln container ecosystem
tools/cartridge-minter Rust CLI for minting new cartridges
.machine_readable/     State, policies, contractiles
----
