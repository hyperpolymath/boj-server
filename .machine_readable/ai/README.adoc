= AI Guidance Directory

Put AI-facing instructions in this folder.

Examples:

* `CLAUDE.md`
* `COPILOT.md`
* `GEMINI.md`
* `AI.djot`

Avoid scattering agent instruction files around the repo root.

Recommended machine read order:

* `0-AI-MANIFEST.deed` (pointer-only front door)
* `boj-server_chora.deed` (`(status)`, `(meta)`, `(agentic)`, `(anchor)`)
* `docs/maintenance/MAINTENANCE-CHECKLIST.adoc`
* `docs/practice/SOFTWARE-DEVELOPMENT-APPROACH.adoc`

A2ML is retired: never add a `.a2ml` file here (`docs/history/A2ML-REMOVED.adoc`).
