= Legacy 6a2 Directory

A2ML is retired. The six descriptiles that lived here were translated into
`boj-server_chora.deed` where a mapping spec allowed, and the files were removed
on 2026-11-14. `docs/history/A2ML-REMOVED.adoc` records what each held and where
its content went.

One file remains:

* `ECOSYSTEM.a2ml` — only its `[publishing.readme]` block, because
  `.github/workflows/readme-derive.yml` (inlined from standards'
  `readme-derive-reusable.yml`) reads that block and nothing else. It goes when
  the reusable reads `ECOSYSTEM.deed` (standards A7 section 10). Do not add
  anything to it.
