= Contractiles Template Set
:toc:
:sectnums:

This directory contains the generalized contractiles templates. Copy the `.machine_readable/contractiles/` directory into a new repo to establish a consistent operational, validation, trust, recovery, and intent framework.

== Contents

Each verb directory holds a Nickel runner, `<verb>/<verb>.ncl`. The runner names
its paired edict, `<Verb>file.deed` in the same directory (A7 8.1). None of the
edicts is written yet: the legacy `<Verb>file.a2ml` contractiles were retired on
2026-11-14 with no mapping spec to translate them
(`docs/history/A2ML-REMOVED.adoc`). Until the edicts exist, the generated
recipes in `contractile.just` stand.

* `must/must.ncl` - required invariants and validations (edict `Mustfile.deed`).
* `trust/trust.ncl` - provenance, integrity and trust-boundary verification (edict `Trustfile.deed`).
* `dust/dust.ncl` - cleanup policy and recovery paths (edict `Dustfile.deed`).
* `bust/bust.ncl` - declared failure modes and their recovery paths (edict `Bustfile.deed`).
* `intend/intend.ncl` - declared purpose and scope (edict `Intentfile.deed`).
* `adjust/adjust.ncl` - accessibility of user-facing interfaces (edict `Adjustfile.deed`).
