== Overview
This directory contains the ReScript/TEA (The Elm Architecture) source code for the BoJ Server's PanLL Panel.

== Architecture
The panel provides a visual "Maître D'" interface for the BoJ Server, allowing users to select cartridges from the Teranga Menu and generate an `order-ticket.scm` without modifying configuration files.
