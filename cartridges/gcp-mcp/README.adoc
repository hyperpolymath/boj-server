== Overview

Google Cloud Platform cartridge for the BoJ server. Provides type-safe access
to GCP services via service account JSON key or OAuth2 token authentication.
Supports Compute Engine, Cloud Storage, Cloud Functions, Pub/Sub, BigQuery,
and IAM with configurable project_id and automatic service endpoint routing.

=== State Machine

`Unauthenticated -> Authenticated -> RateLimited -> Authenticated` (normal flow)

`Authenticated -> Error -> Unauthenticated` (error recovery)

== Architecture

[cols="1,1,2"]
|===
| Layer | Language | Purpose

| ABI
| Idris2
| Formally verified state machine with dependent-type proofs (GcpMcp.SafeCloud)

| FFI
| Zig
| C-compatible implementation with thread-safe session pool, service routing, quota tracking

| Adapter
| V-lang
| REST bridge to BoJ unified adapter protocol
|===

== Building

[source,bash]
----
# Build FFI shared library
cd ffi && zig build

# Run FFI tests
cd ffi && zig build test

# Type-check ABI
cd abi && idris2 --check gcp_mcp.ipkg
----
