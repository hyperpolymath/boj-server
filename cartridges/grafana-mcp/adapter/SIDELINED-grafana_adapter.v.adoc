== Why this file was removed

V-lang was banned estate-wide on 2026-04-12.
The V-lang adapter `grafana_adapter.v` has been replaced by the Zig
three-protocol adapter `grafana_adapter.zig`.

== Replacement

`grafana_adapter.zig` provides identical tool dispatch across three protocols:

* REST (see `build.zig` for port assignment)
* gRPC-compat (same port + 1)
* GraphQL (same port + 2)

The FFI contract is unchanged — `grafana_mcp_ffi.zig` is unmodified.

== Migration notes

* Detection: V-lang is detected via `v.mod` / `vpkg.json`, NOT `.v` extension
  (`.v` files collide with Verilog — this is a V-lang-specific ban).
* The original `.v` adapter is preserved in git history under this commit.
* All tool names and semantics are faithfully preserved in the Zig replacement.
