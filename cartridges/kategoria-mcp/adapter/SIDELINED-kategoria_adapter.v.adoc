== Why this file was removed

V-lang was banned estate-wide on 2026-04-12.
The V-lang adapter `kategoria_adapter.v` has been replaced by the Zig
three-protocol adapter `kategoria_adapter.zig`.

== Replacement

`kategoria_adapter.zig` provides identical tool dispatch across three protocols:

* REST (port 9127)
* gRPC-compat (port 9128)
* GraphQL (port 9129)

The FFI contract is unchanged — `kategoria_ffi.zig` is unmodified.

== Migration notes

* V-lang detected via `v.mod`/`vpkg.json`, NOT `.v` extension (Verilog collision).
* Original `.v` adapter preserved in git history.
* All tool names and semantics faithfully preserved.
