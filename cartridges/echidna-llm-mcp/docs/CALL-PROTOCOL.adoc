== Overview

The `echidna-llm-mcp` BoJ cartridge is the *only* authorised entry point for
all ECHIDNA invocations from other hyperpolymath repos.  All 105 prover
backends are reachable through 8 tools spread across two backend layers.

**NEVER call ECHIDNA directly.** All calls go through BoJ.

== Backend Layers

[cols="1,2,2,1"]
|===
| Layer | Env var | Default | Purpose

| REST | `ECHIDNA_REST_URL` | `http://127.0.0.1:8000` | Proof invocation, discovery, search
| LLM  | `ECHIDNA_LLM_URL`  | `http://127.0.0.1:7721` | Advisory tactic suggestions, prover ranking
|===

The REST layer delegates to the ECHIDNA axum server.
The LLM layer delegates to the ECHIDNA LLM proxy (advisory only —
suggestions are hints, not trust-certified results).

== Tool Reference

=== Discovery

`echidna_list_provers` — no required args::
Returns all 105 prover backends with `name`, `tier`, `category`,
and `complexity` fields.  Call this first to enumerate valid prover IDs.

+
[source,json]
----
{ "tool": "echidna_list_provers", "args": {} }
----

=== Proof Invocation

`echidna_prove` — required: `file`::
Invokes a prover backend on an absolute file path.
Prover is auto-detected from file extension when omitted.

+
[source,json]
----
{
  "tool": "echidna_prove",
  "args": {
    "file": "/path/to/proof.lean",
    "prover": "Lean",
    "timeout_secs": 120
  }
}
----

+
Response shape: `{ verified, message, prover, raw_output, stderr }`

`echidna_verify` — required: `content`, `prover`::
Verify inline proof content as a string.
No auto-detection — `prover` is always required.

+
[source,json]
----
{
  "tool": "echidna_verify",
  "args": {
    "content": "(assert (not true))\n(check-sat)",
    "prover": "Z3"
  }
}
----

=== Corpus Search

`echidna_search` — required: `query`::
Keyword search over 66,674 proofs in the training corpus.
Returns matching examples useful for tactic inspiration.

+
[source,json]
----
{ "tool": "echidna_search", "args": { "query": "induction list append" } }
----

=== LLM Advisory Ops (non-trust-certified)

`echidna_init`::
Initialise the LLM advisory session.  Call once per session.

`echidna_authenticate` — required: `token`::
Authenticate for metered LLM calls.

`echidna_suggest_tactics` — required: `goal`::
Get tactic suggestions from the LLM advisory layer for a proof goal.
Optionally pass `hypotheses` (list of strings), `prover` ID, and `top_k`.

+
[source,json]
----
{
  "tool": "echidna_suggest_tactics",
  "args": {
    "goal": "n + 0 = n",
    "prover": "Lean",
    "top_k": 5
  }
}
----

`echidna_rank_provers` — required: `theorem`::
Rank all applicable prover backends by expected success probability.
Optionally pass `context` and `domain` (`arithmetic`, `logic`,
`type-theory`, `program-verification`, `security-protocol`,
`constraint-solving`, `model-checking`).

+
[source,json]
----
{
  "tool": "echidna_rank_provers",
  "args": {
    "theorem": "forall n : nat, n + 0 = n",
    "domain": "arithmetic"
  }
}
----

== Trust Model

LLM advisory ops (suggest_tactics, rank_provers) are **advisory only**.
They cannot influence ECHIDNA trust levels.  This property is formally
verified in `abi/EchidnaLlm/Protocol.idr::allOperationsAdvisory`.

Proof results from `echidna_prove` and `echidna_verify` carry the full
ECHIDNA trust pipeline (solver integrity, certificate checking, axiom
tracking, confidence scoring).

| `.lean` | `Lean`

| `.fst` | `FStar`
| `.dfy` | `Dafny`
| `.whyml` | `Why3`
| `.mm` | `Metamath`
| `.idr` | `Idris2`
| `.dfg` | `SPASS`
| `.p` / `.tptp` | `Vampire`
|===

# LLM advisory layer (tactic suggestions, ranking)
export ECHIDNA_LLM_URL=http://127.0.0.1:7721    # default
----
